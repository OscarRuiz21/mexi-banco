# Issue tracker

Tracker: GitHub Issues en `OscarRuiz21/mexi-banco`. Acceso con `gh` (cuenta de Oscar en la Mac, `j3l-agentes` en el servidor).

Un issue está listo para un agente cuando tiene `lista-para-agente`, criterio de aceptación observable y no está bloqueado. El reclamo es por rama remota `<tipo>/<numero>` (`~/fabrica/scripts/reclamar.sh`). Ver `~/fabrica/procesos/triage.md`.
