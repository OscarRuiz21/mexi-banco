# Etiquetas de triage

Roles canónicos y su etiqueta en este repositorio (creadas con `~/fabrica/scripts/etiquetas.sh`):

| Rol | Etiqueta |
|---|---|
| needs-triage | `por-triar` |
| needs-info | `falta-info` |
| ready-for-agent | `lista-para-agente` |
| ready-for-human | `lista-para-persona` |
| wontfix | `no-se-hara` |
| (propio) en curso | `en-curso-agente` |
| (propio) vencido | `reclamo-vencido` |

Categorías: `bug`, `enhancement`. Otras etiquetas del proyecto (fase, prioridad, tipo) son otro eje y conviven.
