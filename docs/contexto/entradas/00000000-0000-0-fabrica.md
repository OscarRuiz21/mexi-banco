# El proyecto entra a la fábrica de agentes

**Qué cambió.** Se aplicó la plantilla de la fábrica: `docs/agents/`, `docs/contexto/`, etiquetas de estado y workflows.

**Por qué.** Proceso único para todos los proyectos de J3L, con modos según el rigor que necesita cada uno.

**Qué implica para el siguiente agente.** Leer `AGENTS.md` y `docs/agents/proyecto.md`; reclamar issues con `reclamar.sh`; registrar contexto con entradas, nunca editando `CONTEXT.md`.
